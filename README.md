# Stream

A browser-based screen-sharing site. Screen/audio media travels peer-to-peer over WebRTC. Supabase Realtime is used only for room signaling and presence; media is not uploaded or recorded.

## Local development

1. Copy `.env.example` to `.env`.
2. Set `SUPABASE_URL` and `SUPABASE_PUBLISHABLE_KEY` in `.env`.
3. Run `npm start`.
4. Open http://localhost:3000.

The server loads `.env` locally without requiring a dotenv dependency. The actual `.env` file is ignored by Git.

## Deploy on Render

1. Push this repository to GitHub.
2. In Render, choose **New → Blueprint** and connect this repository.
3. Render reads `render.yaml` and creates the `stream-share` web service.
4. In the service's **Environment** settings, add:
   - `SUPABASE_URL`: your Supabase project URL
   - `SUPABASE_PUBLISHABLE_KEY`: your Supabase publishable key
5. Deploy. Render provides the public HTTPS URL.

The app loads its browser configuration from `/config.js`, generated by the Node server from environment variables. Browser configuration is necessarily visible to visitors. Supabase publishable keys are intended for browser use; never set a Supabase secret/service-role key here.

## Supabase Realtime

The app uses public Realtime channels and presence so viewers can join with a link and without accounts. Ensure public Realtime channel access is enabled for the Supabase project. Do not add broad database RLS policies to `realtime.messages` as a workaround.

## Use

- Open the deployed site and choose **Start a stream**.
- Pick a screen, window, or browser tab. Enable tab audio in the browser picker if you want viewers to hear it.
- Copy the invite link and send it to viewers.
- Keep the host browser tab open while streaming.

## Notes

- Screen capture requires HTTPS; Render provides HTTPS.
- WebRTC uses public STUN servers. Some restrictive networks require a TURN relay; a large audience needs an SFU rather than one peer connection per viewer.
- Browser/OS support determines whether tab or system audio can be captured.
- Refreshing the host page ends the stream. Start a new stream for a new invite link.
